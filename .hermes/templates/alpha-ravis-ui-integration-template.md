# AlphaRavis UI Integration Template

Canonical detailed template lives at:

`docs/ALPHARAVIS_UI_INTEGRATION_TEMPLATE.md`

Use that document when wiring any browser UI to AlphaRavis/LangGraph. It defines
expected public env vars, LangGraph SDK calls, thread lifecycle, attachment/state
shape, preview policy, Monaco lazy-load policy, and the manual smoke checklist.
